Lamaerk builds research-driven, production-grade software for crypto markets.

This GitHub Organization hosts Lamaerk's open-source experiments, designs, and production-ready code.

Among other things, we are currently building:

- [gateway](https://github.com/lamaerk/gateway): Management API, authentication, billing, usage tracking, and PostgreSQL persistence.
- [webapp](https://github.com/lamaerk/webapp): Public website and dashboard for managing Rungst accounts, subscriptions, connections, and usage.
- [stream](https://github.com/lamaerk/stream): A Rust-based, real-time Solana trade stream and WebSocket backend.
- [docs](https://github.com/lamaerk/rungst-docs): Public documentation for Rungst and its developer APIs.
